Re : Accès à distant à une BDonnees

Bonjour,


1) pgAdmin 3 et 4 sont traduits en français.  Je ne sais pas trop si la langue d'affichage se base sur les préférence de la session qui l'utilise ou s'il faut le configurer explicitement, mais avec un minimum de recherches vous devriez pouvoir régler le soucis (je n'utilise pas ces outils donc difficile d'être plus précis)


2) il suffit de configurer le paramètre listen_addresses et configurer l'authentification selon vos besoin dans le pg_hba.conf (https://www.postgresql.org/docs/current/runtime-config-connection.html#GUC-LISTEN-ADDRESSES et https://www.postgresql.org/docs/current … conf.html)


3) vous pouvez configurer pgadmin4 en version "serveur web", et dans ce cas une seule installation est suffisante pour plusieurs utilisateurs.

Julien.
https://rjuju.github.io/

Re : Accès à distant à une BDonnees

Comme le message n'a rien à voir avec un problème du fichier pg_hba.conf, ça n'est pas très étonnant. Julien vous demande si vous avez redémarré le serveur après la modification du paramètre listen_addresses (seul moyen pour prendre en compte cette modification). Est-ce que cela a été fait ?

Sinon, la seule autre raison possible est qu'un élément réseau vous bloque. Routeur ou firewall. À noter que "Timeout expired" n'est pas un message d'erreur PostgreSQL, donc le problème vient d'ailleurs.

Guillaume.
