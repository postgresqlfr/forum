Re : calcul de pourcentage sur une colonne

Bonjour,
vous pouvez faire une requête du genre :

SELECT mois,round(nb::numeric/count(*)*100,2)
FROM table
JOIN (
	SELECT mois,count(*) as nb
	FROM table
	WHERE valeur is not null
	GROUP BY mois
) sql  using (mois )
GROUP BY mois,nb
