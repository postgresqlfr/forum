Re : déplacer le dossier data

Vous arrêtez PostgreSQL, vous déplacez le répertoire, vous configurez l'emplacement du nouveau répertoire (soit dans le script de démarrage, soit, bien plus propre, dans un fichier de configuration sous /etc/sysconfig), puis vous redémarrez PostgreSQL.

Je ne sais pas spécialement pour CentOS mais certaines RedHat n'aiment pas trop ça à cause de la configuration de SELinux.

Guillaume.
