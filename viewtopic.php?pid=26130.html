Re : [RÉSOLU] utiliser la Base postgres pour stocker des données

Vous pouvez supprimer la base postgres cela ne gênera pas le fonctionnement des autres bases.


Attention toutefois, beaucoup d'outils s'en servent de "base de maintenance" (comprendre base de connexion par défaut), donc en recréer une vide est tout de même fortement conseillé.
