Ecriture dans tablespace specifique

Bonjour,

J'utilise  postgreSQL 9.5 sur un PC Windows 10.
Je suis administrateur de ce PC.

J'utilise PostgreSQL avec pgadmin 3 pour stocker des fichiers shape QGIS.

J'ai débuté l'été dernier avec PostgreSQL et jusqu'à présent, je suis toujours arrivé à ce que je voulais grace à ce forum en particulier.
Je suis toujours en phase de test, avant de déployer ma base SIG.


Mon problème est le suivant, il est basique, mais comme je suis bloqué, je me tourne vers vous.

J'ai une base qui fonctionne bien avec des tables stockées dans le tablespace pg_default.

J'ai créé une autre base de données avec un tablespace specifique, localisé sur une partition dédiée de mon PC.
Les créations de la tablespace et de la base de données ont l'air de bien se passer, mais dès que je veux charger un fichier shape dans cette base de données, le "Postgis shapefile import export manager" échoue sans aucun message d'erreur.

Je précise que le même fichier shape s'importe bien dans la base utilisant pg_default.

La base et la tablespace ont le même propriétaire.

Est ce que, coté Windows, il faut des droits particuliers, ou un utilisateur particulier, faut il un utilisateur Postgres par exemple ?
