Re : Boquer a l'instalation

L'édition familiale est une version restreinte de la version pro. C'est pour cela que vous n'avez pas le plugin « Utilisateurs et groupes » dans l'outil de gestion de l'ordinateur. D'après mes quelques recherches, il vous faut démarrer en mode sans échec. Si l'outil ne vous le permet toujours pas, utilisez mmc pour ajouter ce plugin (ils parlent de « composant logiciel enfichable » Utilisateurs et groupes locaux).

Guillaume.
