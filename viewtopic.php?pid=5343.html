Re : [Windows 7] Installation impossible Version 8.4.4-1

Le message intéressant dans tout ça, c'est : Il n'y a pas de moteur de script pour l'extension de fichier ".vbs". Ce qui laisse entendre que VBScript n'est pas (ou mal) installé. Je suppose que ça laisse aussi entendre qu'il ne s'agit pas d'un windows 7 pro (mais c'est juste une devinette de ma part).

Donc, ce qu'il me semble possible de faire. Commencez par rechercher vbscript.dll. Si vous le trouvez, enregistrez la de nouveau avec regsvr32. Sinon installez le Windows Script. C'est plutôt bien expliqué sur http://groups.google.com/group/microsof … 1?lnk=raot .

Guillaume.
