Re : Installation des outils serveurs

Je ne comprends pas puissqu'il est mentionné ceci : "... est inclus en tant que module contrib pour toutes les versions de PostgreSQL, à partir de la version 8.2"

Un module contrib est un module à installer. C'est même appelé une extension à partir de la 9.1. Le message d'astuce comporte un troisième bouton vous permettant d'installer automatiquement l'extension (ie le module contrib) manquant avec pgAdmin 1.14. Dans le cas contraire, cela signifie que vous n'avez pas compilé les modules contrib.

Faut-il faire une manipulation de plus pour bénéficier des outils serveurs?

Oui, le message indique qu'il faut installer le module adminpack.

Mais ceci n'est qu'une solution de contournement. Le problème est-il réellement résolu?

Vous avez juste caché l'alerte. Casser le thermomètre ne fait pas partir la température. Il fait simplement que vous ne la voyez plus.

N'est-ce pas un avertissement qui pourrait être bloquant pour d'autres opérations de sauvegarde par exemple?

Non, absolument pas. Le module adminpack permet de lire les journaux applicatifs à distance et de modifier les fichiers de configuration à distance. Les deux peuvent être intéressants mais ne sont pas nécessaires.

Guillaume.
