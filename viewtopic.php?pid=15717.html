Re : problème de connexion avec phppgadmin

Quelle version de phppgadmin utilisez-vous ? La dernière release (5.0.4) n'est compatible qu'avec postgres 9.1. Il faut utiliser la version de développement (https://github.com/phppgadmin/phppgadmin/) pour la compatibilité 9.2.

Si vous vous connectez en tant que postgres, avez vous bien modifié ce paramètre dans le config.inc.php: $conf['extra_login_security'] = false;


Pour activer les traces, vous pouvez utiliser ce paramètrage dans le postgresql.conf:

logging_collector = on
log_destination = stderr
log_directory = pg_log
log_min_error_statement = error


et redémarrer postgres. Vous devriez voir les messages dus aux tentatives de connexion.

Julien.
https://rjuju.github.io/
