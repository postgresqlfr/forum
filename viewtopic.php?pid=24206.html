Re : mot de passse pgadmin 4

Je ne crois pas qu'il y ait une fonction pour récupérer votre mot de passe ni le réinitialiser.  Vous avez quatres solutions :

- supprimer toute la configuration de pgadmin4 pour repartir de zéro
- renommer la base sqlite, refaire l'initialisation, récupérer le hash du mot de passe dans la table "user" et le modifier dans la même table de la base renommée, puis restaurer la base sqlite au nom d'origine
- s'inspirer du script setup.py pour générer un hash d'un mot de passe et le modifier dans la table "user" de la base sqlite (cf do_setup() et encrypt_password())
- demander sur la mailing list pgadmin-support

Julien.
https://rjuju.github.io/
