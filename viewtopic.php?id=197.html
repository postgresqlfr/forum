Re : Pugin firefox pour recherche dans la doc

J'avoue que je ne comprends pas bien pourquoi cela ne fonctionne pas. Le seul moyen actuellement de les installer est de copier le fichier correspondant à votre version (à savoir http://docs.postgresql.fr/addon/pgfr-docs83-ff.xml pour la 8.3, http://docs.postgresql.fr/addon/pgfr-docs82-ff.xml pour la 8.2 et http://docs.postgresql.fr/addon/pgfr-docs81-ff.xml pour la 8.1) dans le répertoire searchplugins de votre profile firefox (~/.mozilla/firefox/<votreprofile>/searchplugins). Ceci fait, il suffit de redémarrer firefox.

Mais c'est clairement pas une solution à long terme.

Guillaume.
