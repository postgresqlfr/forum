Je suis pas sur d'avoir bien compris la question...

De mémoire, le lien de démarrage de pgadmin doit se trouve  là : Demarrer > Programmes > PostgreSQL 8.2 > pgAdmin3

Pour utiliser la commande psql, tu peux faire la manipulation suivante :   Démarrer > Executer
puis taper les commandes :

cd  c:\Program Files\PostgreSQL\8.2\bin"
psql.exe -U postgres
