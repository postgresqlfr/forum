Erreur CETFATAL - Warm Standby

Bonjour,
j'ai mis en place le système de backup Warm Standby.
Tout fonctionne très bien mis à part une petite chose.

Je tourne sous Windows avec la version 8.4.2

Quand je lance mon serveur de backup en ligne de commande, j'ai le message d'erreur suivant :
CETFATAL:  the database system is starting up

Or mon serveur est bien démarré vu que les processus tournent.
Mes fichiers WAL sont bien restaurés sur mon serveur de backup (les messages apparaissent).

Mais j'ai toujours le message  CETFATAL ....... de temps en temps en chaque message de restauration de fichier.

Et dès que je crée mon fichier pour arrêter la restauration, le serveur démarre normalement sans message d'erreur.

Merci

Re : Erreur CETFATAL - Warm Standby

Les messages « FATAL:  the database system is starting up » indiquent seulement qu'une personne essaie de se connecter au serveur qui se trouve en cours de restauration. Or il est impossible de se connecter sur le serveur en cours de restauration.

Pour avoir cette possibilité, il va falloir attendre la prochaine version, la 9.0, prévue pour cette année (entre juillet et septembre de cette année).

Guillaume.

Re : Erreur CETFATAL - Warm Standby

Pour compléter ce qui a été dit, la 8.5 est renommée 9.0 (http://blog.guillaume.lelarge.info/index.php/post/2010/01/21/Oubliez-la-8.5...) vu l'ajout de la fonctionnalité des esclaves en lecture seule ainsi que l'ajout d'une autre fonctionnalité très intéressante : le streaming des transactions par groupe (et non plus par journaux complets). Voir http://blog.guillaume.lelarge.info/inde … eplication pour deux/trois détails supplémentaires.

D'autre part, concernant la recherche sans accent, il existe un module contrib dans la 9.0, nommé unaccent, qui permet cela. Voir http://blog.guillaume.lelarge.info/inde … -le-retour pour une démo complète de ce module contrib.

Guillaume.
