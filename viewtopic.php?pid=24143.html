Migration SQL Server 2012 vers PostgreSQL 9.6

Bonjour,

S'il vous plaît dans l'optique d'effectuer la migration de ma base de données SQL Server 2012 vers PostgreSQL 9.6, j'aimerais savoir si la version 9.6 de PostGreSQL offre les fonctionnalités ci-dessous :


les Sauvegardes partielles?
les Sauvegardes différentielles?
les Sauvegardes multiples?
les Sauvegardes compressées?
les Sauvegardes multi-fichiers?


la Restauration avec arrêt à transaction?
la Restauration de pages endommagées?
la Restauration en ligne?
la Vérification d'intégrité physique?
la Vérification d'intégrité logique?
le Clustering?
l'Intervention hardware à chaud?


l'Audit de sécurité des données : Permettre par exemple de savoir qui, quand et sur quel objet a été fait un SELECT, INSERT, UPDATE DELETE, MERGE, etc.?
l'Audit légaux?
l'Audit de changement pour pouvoir alimenter un datawarehouse par différence et non plus par reconstruction?
l'Audit d'exécution?
l'Espace de stockage "Read Only"?
l'Espace de stockage pré dimensionnés?
les Journaux de transaction pré dimensionnés?
Un journal de transaction par base?
Un journal de transaction pour les tables
temporaires?


l'Optimisation statistique automatique?
l'Optimisation sémantique?
les Indicateurs de requête?
la Réinjection de plan de requête?
la Création des statistiques d'optimisation?
la Statistiques d'exécution?
l'Assistant de tuning?
la Limitation de coût de requête?
le Gouverneur de ressources pour limiter les ressources CPU ou RAM de certains utilisateur?


la gestion d'Index couvrants pour les colonnes ajoutées dans une clause INCLUDE pour éviter les doubles lectures (index + table) et assurer la couverture de la requête par le seul index?
l'Index XML?
l'Indexation textuelle doc. électronique?


une solution de Business intelligence intégrée?
un Serveur multi instance?
un Cliché de bases de données?
le Parallélisme des requêtes?
le Parallélisme d'accès disque?
un Stockage de fichier (DataLink)?
les Transactions explicites, Transaction imbriquées, Transaction DDL?
des Vues partitionnées distribuées?
des Vue matérialisées?
des Déclencheurs INSTEAD OF?
des Déclencheurs DDL?
un Opérateur d'intra jointure c'est à dire permet de joindre une fonction table ou un nœud XML extrait d'une colonne d'une table de la requête?
la Réplication de données?


Afin de m'assurer de pouvoir effectuer l'ensemble des opérations sur ma futur base de données.

Merci
