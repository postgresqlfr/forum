Re : Ajouter une table

L'ordre CREATE TABLE n'est compatible qu'avec MySQL, vous ne pourrez pas exécuter correctement ça sur un serveur PostgreSQL. Vous devez trouver l'ordre SQL équivalent pour PostgreSQL. À condition que vous avez bien une base de données PostgreSQL.

Guillaume.
