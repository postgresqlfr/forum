Re : Pb installation sous windows 7: prerunscript.command.line.error

L'erreur est affichée : "Erreur CScript: Impossible de trouver le moteur de script "VBScript" pour le script "C:\temp\postgresql_installer_b9d290be24\prerun_checks.vbs"." Il s'agit d'un problème avec votre installation windows. Il est nécessaire de pouvoir lancer des fichiers vbs pour utiliser l'installeur graphique.
