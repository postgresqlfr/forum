Re : INTEGRER une DB POSTGRES externe dans une nouvelle install

C'est impossible. Pour récupérer une base à partir des fichiers, vous devez avoir l'intégralité du répertoire des données. Là, vous n'avez que les fichiers d'une base, c'est perdu d'avance.

Re : INTEGRER une DB POSTGRES externe dans une nouvelle install

À partir du moment où vous avez le répertoire qui contient base, global, pg_clog, pg_xlog, etc, ainsi que les répertoires de chaque tablespace, vous pouvez vous en sortir. Sinon, il ne reste que les sauvegardes. Content que vous en ayez trouvé un récent.

Guillaume.
