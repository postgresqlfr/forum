problème de connexion ODBC

Bonjour

j'ai installé une base Postgres sur un portable pour faire une démo en réunion.
comme l'UI tourne sous Access, il faut aussi configurer une connexion ODBC.
j'ai attribué la même adresse ip au portable quelle celle du serveur ou tourne postgres pour ne pas avoir à refaire l'UI, sauf que ça ne fontionne pas:
je configure ma connexion ODBC via les outils d'administations de windows et quand je teste la connexion cela marche en "localhost" mais pas avec l'ip 192.168.1.64!!
j'ai modifié les fichiers pg_hba.conf

host	 Indext	 		all	 			192.168.0.0/0		    md5

comme le portable n'est pas connecté à aucun réseau, je pense que ça vient de là! quand je fais un ipconfig, il ne me renvoie pas d'adresse ip

merci d'avance

Re : problème de connexion ODBC

je me reponds à moi même, la pause déjeuner m'ayant été bénéfique!!

finalement c'est bien un problème d'ip : dans la chaine ODBC, l'ip est présente
j'ai donc modifié la connexion odbc en localhost, lié de nouveau toutes les tables et vues nécessaires dans le fichier Access avec cette nouvelle connexion ODBC et ça fonctionne!
