Re : slony, windows xp et windows server

alors en gros les renseignement qu'on a sont les suivants :
il n'y a pas d'erreur dans les logs.
avec xp en maitre et le serveur en esclave ça marche mais l'inverse non

quand on met le serveur en maitre, l'esclave possède bien le cluster slony mais ne créé pas les triggers qui bloque les modifications. peut-etre que l'on ne'enregistre pas le service correctement. on utilise la commande comme ceci :
C:\Program Files\PostgreSQL\8.3\bin>sc create Slony-I binpath= "C:/Program Files/PostgreSQL/8.3/bin/slon.exe -service" depend= "RPCSS"   1>>C:/slony/Test/log.txt 2>&1

puis on fait un : net start Slony-I
voilà , on comprend pas trop pourquoi ça marche que d'en un sens :s.
