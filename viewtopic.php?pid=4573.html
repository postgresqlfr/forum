Re : [TimeOut] sur application tiers

Votre application utilise le pilote Npgsql pour se connecter à la base de données PostgreSQL. Le pilote indique simplement à votre application que la dernière requête exécutée a duré plus de temps que le délai maximum configuré et que la requête a donc été annulé. Je pense que, pour que Npgsql soit au courant de cette information, c'est que le délai lui a été donné par l'application. Donc, soit vous avez une configuration possible de ce délai sur l'application, soit c'est une valeur non modifiable. Dans tous les cas, il faut se retourner auprès du fournisseur de l'application pour qu'il vous indique comment faire ou pour qu'il corrige son application.

Guillaume.
