Re : Problème pour importer fichier .sql (débutant)

Bonjour.

Le message "La requête a été exécutée avec succès en 16 ms, mais ne renvoie aucun résultat. " correspond à la dernière instruction du fichier (GRANT ALL ON SCHEMA public TO PUBLIC;) et ne renvoie effectivement aucun résultat.

Si vous actualisez la base de donnée dans pgAdmin (je suppose que c'est de cet outil dont vous parlez) vous devriez voir votre base de donnée restaurée avec toutes les tables etc...

PS: votre script contient des noms et prénoms, il serait préférable de ne pas laisser trainer ça je pense s'il s'agit de vraies données.

Re : Problème pour importer fichier .sql (débutant)

Lorsque vous avez cliqué sur la petite loupe pour ouvrir une requête sql, étiez-vous sur l'arborescence de a base de donnée postgres ou la base de donnée Ecole ?

Vous pouvez vérifier dans le schéma public de la base de donnée postgres si les tables n'ont pas été crées sur cette base de donnée.

Pour information, vous pouvez voir à tout instant quelle est la base de donnée utilisée dans cette fenêtre en regardant les informations de connexion dans la barre en haut à droite , cela affiche "nom_base sur user@serveur : port"
