Re : type serial.

C'est pas un soucis, c'est normal. serial est un pseudo type qui dit à PostgreSQL de créer une colonne de type integer et de lui associer une séquence pour l'autonumérotation. Voir la doc sur http://docs.postgresql.fr/9.0/datatype. … ype-serial
