Problème d'installation PostgreSQL 8.2 avec Windows Server 2008...

Bonjour,

je suis, actuellement, dans l'impossiblité d'installer PostgreSQL, en version 8.2, sous Windows Server 2008.
En effet lors de l'installation de PostgreSQL j'ai systématiquement le message d'erreur suivant :

Echec lors du lancement d'initdb : -1073741502!
Merci de lire le journal des traces dans "C:\DB\tmp\initdb.log".
Note ! Vous devez lire/copier ce journal des traces avant de cliquer sur OK ou il sera automatiquement supprimé.

-- OK --

Hors le fichier indiqué par le message ci-dessus n'existe pas.

J'ai essayer en passant le paramètre " DOINITDB=0 " lors de l'installation. Dans ce cas l'installation fonctionne mais il m'est alors impossible d'executer " initdb " manuellement

-- Installation en ligne de commande --
msiexec /i "postgresql-8.2-int.msi"
  INTERNALLAUNCH=1
  DOINITDB=0
  ADDLOCAL=server,psql
  SERVICEDOMAIN="%COMPUTERNAME%"
  SERVICEACCOUNT="%ServiceAccount%"
  SERVICEPASSWORD="%ServicePassword%"
  CREATESERVICEUSER=1
  SUPERPASSWORD="%SuperPassword%"
  ENCODING="UTF-8"
  PERMITREMOTE=1
  BASEDIR="C:\DB"
  TRANSFORMS=:lang_fr
  /qb!

-- Initialisation de la DB en manuel --
initdb -D "C:\DB\data" -E="UTF-8" -u="postgres -W --no-locale

Dans le dernier cas j'ai un autre message d'erreur. Celui-ci m'indique qu'il lui est impossible de trouver le fichier " postgres.exe " alors que celui ci se trouve pourtant bien dans le même répertoire (à savoir "C:\DB\bin") que " initdb.exe ".

L'un d'entre vous serait me dire :
- S'il est arrivé à installer PostgreSQL v8.2 sous Windows Server 2008 ?
- Si oui, comment y est-il parvenu ?

J'ai effectué des tests de compatibilité lors de la mise à disposition de la version RC1 de Windows Server 2008 et je n'avais absoluement pas rencontré ce genre de soucis.
