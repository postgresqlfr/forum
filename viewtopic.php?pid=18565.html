Purge dossier pg_xlog

Bonjour à tous,

Etant novice sur ce sujet je vous expose le problème:

Sur un serveur de production, le dossier pg_xlog génère des fichiers de 16 Mo (d'après ce que j'ai compris, cela permet de faire une restauration, ces fichiers WAL décrivent chaque modif sur la base de donnée). Notre problème est que nous recevons des alertes quotidiennes car notre disque contenant ces fichiers est plein

C’est un volume de 30 Go qui est donc rempli à 97 %

D'après différentes forums il est fortement déconseillé de supprimer les fichiers dans le dossier pg_xlog  car on risque de perdre des données. Idem pour le fichier  pg_resetxlog, apparemment cela sert principalement si les fichiers WAl sont corrompus...

Re : Purge dossier pg_xlog

> D'après différentes forums il est fortement déconseillé de supprimer les fichiers dans le dossier pg_xlog  car on risque de perdre des données. Idem pour le fichier  pg_resetxlog, apparemment cela sert principalement si les fichiers WAl sont corrompus...

Vous ne devez jamais supprimer des fichiers dans le répertoire pg_xlog. Vous risquez de corrompre votre base, voire pire ne pas pouvoir redémarrer.

Avec un checkpoint_segments à 16, vous devriez avoir en général 3*16*16 Mo d'utilisation disque. Si vous avez plus, c'est que PostgreSQL ne peut pas faire autrement et que votre checkpoint_segments est bien trop bas. Ou autre possibilité, votre archivage est tellement lent qu'il ne tient pas la charge.

Guillaume.
