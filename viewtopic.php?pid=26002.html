Re : Istallation version 9.6 configuration

Bonjour,


Tout d'abord, il faut modifier le fichier pg_hba.conf et non le pg_hba.conf.sample.  Sauf exception (par exemple sur debian/ubuntu, mais vous n'avez pas précisé le système que vous utilisez), ce fichier est situé à la racine du répertoire de données de l'instance.  Après les modifications, il faut recharger la configuration (encore une fois, ça va dépendre du système).  Pour le reste, il s'agit d'un système de filtrage qui marche de manière similaire aux systèmes de filtres des firewall.  Difficile de dire si vous devez remplacer, modifier ou autre sans savoir ce que vous avez ni ce que vous voulez faire.  Je vous conseille de lire attentivement la documentation suivante qui devrait répondre à beaucoup de questions : https://docs.postgresql.fr/9.6/client-a … ation.html

Re : Istallation version 9.6 configuration

Lorsque vous avez installé postgres, vous avez du choisir un répertoire pour les binaires et un répertoire pour les données.  C'est peut être par défaut dans « c:\Program Files\PostgreSQL\9.6\data », mais je n'en suis pas sur.  Par répertoire racine j'entends ce répertoire et non pas un des sous répertoires.



pgAdmin4 est un client, c'est le serveur que vous devez recharger.  Je ne sais pas comment le faire sous windows, à part appeler "pg_ctl.exe -D le_repertoire_data reload",  en supposant que vous savez où se situe pg_ctl.exe et où est le répertoire de données.
