Re : 64-bit

Sous Windows, il n'existe actuellement qu'une version 32 bits. Elle fonctionne sous un Windows 64 bits mais ne pourra pas profiter de l'espace d'adressage 64 bits. Cela étant dit, ce n'est pas un gros problème vu qu'il est généralement considéré qu'il ne faut pas donner trop de mémoire à PostgreSQL sous Windows (c'est contreproductif).

Guillaume.

Re : 64-bit

en fait l'intérêt d'une compilation windows 64 bits serait aussi pour les modules cients.
Par exemple les dlls (pg/odbc) qui pourraient alors être utilisé par des produits nécessitants obligatoirement des dll 64 bits.
Je pense à Manifold pour le traitement de gros volumes de donnée directement accessibles en db pg.
La version 32 bits fonctionne avec manifold 32 bits, mais c'est dommage d'avoir une station de travail sous w7 avec 32 go de ram et de ne pas pouvoir en tirer partie. Dans ce cas, la remarque client est : mais c'est de la m... pourquoi ?

Donc même si la partie serveur n'a pas d'utilité, un build propre et fonctionnel pour les clients serait un vrai plus dans l'adoption de note éléphant préféré.
Cordiales saluations.
