Re : Récupéartion d'un cluster détruit?

La réinstallation des binaires postgres n'a aucun rapport avec les données qu'il stocke.  À moins que vous n'ayez détruit le container ou supprimé le répertoire data de postgres, vous devriez pouvoir redémarrer l'instance avec les nouveaux binaires en pointant sur les anciennes données.
