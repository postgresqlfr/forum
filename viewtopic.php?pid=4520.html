Bonjour,

J'ai installé sous Windows PostgreSQL 8.4 et Slony 2.0.2.

Suite au message précédent concernant "Slony/PG8.4 sous Windows" http://forums.postgresql.fr/viewtopic.php?id=542, je souhaiterais savoir si Slony 2.0.2 est une version stable et si cette version peut être utilisée avec PostgreSQL 8.4.

Je souhaite créer un système de réplication sur trois serveurs, je dois donc installer PostgreSQL et Slony sur ces trois serveurs, est-ce bien cela?

J'utilise la documentation http://www.pgadmin.org/docs/dev/slony-install.html pour créer le système de réplication.

Sur le premier serveur, avec l'outil pgAdmin III, j'ai créé un Cluster contenant 2 nœuds : Master Node et pgAdmin Node.
Quelle est la procédure à suivre pour créer un nœud "esclave" sur un deuxième serveur ?
