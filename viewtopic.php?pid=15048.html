Re : Blocage BDD postgresql et mot de passe n'est plus valide

Il s'agit d'un probllème de mot de passe. Si vous ne l'avez pas changé, ni sur le serveur ni dans votre configuration pgAdmin, c'est que quelqu'un d'autre l'a changé. Il vous faut donc modifier le pg_hba.conf pour autoriser votre ip à se connecter sans mot de passe pour le remodifier.
