bonjour,

j'ai le problème suivant:

* sur le poste srvA j'ai installer debian6 + postgresql (via apt-get)
* sur le poste srvB j'ai installer debian6 + postgresql -client
* sur le poste srvC j'ai installer windows7 + postgresql + odbc+ pgadmin

mon poste srvA est configuré ainsi pour le fichier postgresql.conf

root@srvA:/var/log# cat /etc/postgresql/8.4/main/postgresql.conf |grep "listen " 
   listen_addresses =  '*'                 # what IP address(es) to listen on;
root@srvA:/var/log# cat /etc/postgresql/8.4/main/postgresql.conf |grep "ssl ="
   ssl = false #true                               # (change requires restart)
root@srvA:/var/log# cat /etc/postgresql/8.4/main/postgresql.conf |grep "port ="
   port = 5432                             # (change requires restart)

et ainsi pour le pg_hba.conf

local   all         postgres                          ident
host    all         all         0.0.0.0/0             password

le pare feu du poste srvC est désactivé ...
