Re : Mot de passe postgres

Après vérification, il se trouve que sur windows 7, l'utilisateur postgres n'apparait pas dans la liste des utilisateurs via le panneau de configuration (car il ne fait pas partie du groupe utilisateur).

Vous pouvez dans l'invite de commande exécuter : "net user"
Si l'utilisateur postgres apparait, c'est qu'il est toujours présent.

Vous pouvez essayer "net user postgres /delete" pour le supprimer et ensuite refaire l'installation comme dans le guide indiqué par gleu.
