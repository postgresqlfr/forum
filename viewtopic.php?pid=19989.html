Re : quelle distribution de debian possède la dernière posgresql 8.3 ?

L'installeur graphique est disponible ici : http://www.enterprisedb.com/products-se … pgdownload (apparemment la 8.3 est toujours fournie). Sinon pour compiler, c'est configure make et make install (avec installation de quelques dépendances comme la libreadline-dev etc). Il y a de la documentation ici pour l'installation par compilation : http://www.postgresql.org/docs/current/ … edure.html
