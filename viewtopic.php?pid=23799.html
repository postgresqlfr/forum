Re : Les différents types d'objets sous PostgreSQL et paramètre commun

Il existe plein d'autres types d'objets : fonctions, schémas, domaines, types, opérateurs, séquences, etc.

Deux bases de données peuvent avoir une configuration différente, mais ça ne se fera pas au niveau du postgresql.conf. Il faut utiliser ALTER DATABASE dans ce cas. Voir http://docs.postgresql.fr/current/sql-a … abase.html pour les détails.

Guillaume.
