Re : HP Device Manager : FATAL: no pg_hba.conf entry for host "::1", user

S'il s'arrête, vous devez avoir d'autres lignes dans le journal des événements indiquant pourquoi il s'arrête.

Sinon, pour le fichier pg_hba.conf, il faudrait ajouter la ligne suivante :
host    all    all   ::1/128   md5

Ça devrait aider.

Guillaume.
