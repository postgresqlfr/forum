Re : environnement minimal pour Postgresql

Tout d'abord, merci de ne pas multiplier les messages pour votre problèmes (voir http://forums.postgresql.fr/viewtopic.p … 18#p20918).

PgAdmin3 est un client pour se connecter à une base PostgreSQL. Si vous n'avez pas de base postgres, il est effectivement nécessaire d'en installer une. Cela dépend en fait de ce que vous cherchez à faire.

Sinon, par défaut la base postgres est intialisée avec un utilisateur "postgres" super utilisateur qui n'a pas de mot de passe. La connexion est possible en ligne de commande en tant qu'utilisateur système postgres. Pour vous connecter, vous pouvez faire ainsi :

user@host:~$ sudo su - postgres
[sudo] password for user: 
postgres@host:~$ psql

psql (9.3.5, serveur 9.1.14)
Saisissez « help » pour l'aide.

postgres=#

Vous pouvez alors assigner un mot de passe à votre utilisateur postgres si vous le voulez (par exemple : « ALTER USER postgres WITH PASSWORD 'monmotdepasse'; »).

https://rjuju.github.io/
