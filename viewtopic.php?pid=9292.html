Re : Migration oracle -> Postgres, compatibilité modules

Il n'y a pas vraiment d'équivalent à ces fonctionnalités.

Pour XML database, on a des extensions XML dans postgres. Mais je doute qu'elles fonctionnent à l'identique.
Pour Oracle TEXT, dans PostgreSQL, ça s'appelle le full text, il y a tout un chapitre dans la doc sur le sujet. Pareil, ça ne sera pas compatible (on pourra migrer le texte à indexer, mais la requête de recherche et le code d'indexation seront différents.
Pour les security labels, je ne me rappelle plus exactement comment ça fonctionne sous Oracle. Je doute qu'il y ait un équivalent à l'identique… si c'est rajouté des informations de sécurité par enregistrement, il y a des nouveautés sur ce sujet dans la version 9.1.

Marc.
