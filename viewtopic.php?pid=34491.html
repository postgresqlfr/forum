Re : pour le superutilisateur***unknown variable superacoun***)

Bon, je vais m'auto-repondre.

-Le superutilisateur unknown est : postgres (il est écrit dans le récapitulatif qui précède l'installation, vous choisirez le mot de passe avant).

-Attention: l'utilisateur par défaut est votre utilisateur du système, vous ne vous connecterez pas avec cet utilisateur. Il faut préciser l'utilisateur a utiliser qui sera "postgres"

-Attention: le mot de passe que vous choisissez est valable pour le super utilisateur "postgres" qu'il faudra donc préciser en vous connectant.

Pour utiliser cet utilisateur, ajoutez en premier lieu le dossier postgreSQL à vos variables d'environnement (rechercher variables d'environnement dans la recherche windows), dans le champ "path".

Puis depuis une console, les commandes utilisées doit être suivie de -U postgres. (Grand U).

Les commandes se trouvent dans le dossier "bin" de postgre, elles sont au format exécutable. Il n'est pas envisageable de les utiliser simplement en les ouvrant puisqu'elles doivent être suivies d'instructions.

Voilà, merci pour ma réponse. Bonne journée

Mais lors de la connexion avec psql on me demande le mot de passe de berou qui est le nom de mon compte sur ma machine.
et là j'ai quelque soit ma saisie un refus :

Mot de passe pour l'utilisateur berou :
psql: erreur : la connexion au serveur sur « localhost » (::1), port 5432 a échoué : FATAL:  authentification par mot de passe échouée pour l'utilisateur  « berou »


psql se connecte par défaut avec le nom du rôle correspondant au nom d'utilisateur côté système d'exploitation, donc "berou" dans votre cas.  Vous devriez essayer "psql -U postgres", s'il s'agit du compté créé par l'installeur que vous utilisez.  Sinon, vous pouvez consulter https://docs.postgresql.fr/16/auth-pg-hba-conf.html pour configurer postgres sans avoir besoin de saisir de mot de passe le temps de créer le(s) rôles nécessaire(s) et/ou modifier les mots de passe.
