rjuju
Administrateur

Re : Probleme installation PostgreSQL Windows 7

L'installeur a créé un compte superutilisateur nommé «postgres» : Executing cscript //NoLogo "C:\Program Files\PostgreSQL\9.2\installer\server\loadmodules.vbs" "postgres" "****" "C:\Program Files\PostgreSQL\9.2" "C:\Program Files\PostgreSQL\9.2\data" 5432

SI vous vous connectez avec psql, il faut utiliser l'option -U postgres. SI vous utilisez pgadmin, il faut spécifier le nom de l'utilisateur dans la case correspondante.

Julien.
https://rjuju.github.io/
