Re : supervision de la réplication

Vous pouvez consulter la vue pg_stat_replication si vous utilisez une version 9.1 ou supérieure, sinon regardez du côté de check_pgactivity, et l'action streaming_delta (ou hot_standby_delta si vous êtes en 9.0) : https://github.com/OPMDG/check_pgactivity/releases

bonjour,

Vous pouvez aussi lancer les requêtes suivantes :
sur le master : select pg_current_xlog_location();
sur le slave : select pg_last_xlog_receive_location();

et comparer les résultats qui doivent être identiques.
