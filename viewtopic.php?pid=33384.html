Communication PostgreSQL - Supervision PCVue

Bonjour,

Alors voilà, je suis technicien BE informatique industrielle et je dois réaliser un projet.

Ce projet est composé de deux parties :Première partie, qui est la base de données (donc avec Postgre), et la deuxième partie, la supervision avec PCVue.

Le projet consiste à venir lire un code avec une caméra, ce code est envoyé à une base de données (qui s'incrémente à chaque lecture d'un code) puis ensuite doit envoyer ces données à la supervision (pour les afficher sur un écran).

C'est la première fois que j'utilise la base de données PostgreSQL, j'aurais donc voulu savoir si certains ont déjà réussi à communiquer une BDD Postgre avec une supervision PCVue.
Je suis partie sur la piste que, la base de données exporte ses données dans un tableau EXCEL, qui ensuite sont reprises par la supervision (en important le fichier excel).
Je suis en cours de tests, mais auriez-vous des propositions avec des idées peut-être plus simples ou plus concrètes ?

En vous remerciant par avance !

Cordialement

Thomas

Re : Communication PostgreSQL - Supervision PCVue

Bonjour,


Je ne connais rien à PCVue (je ne savais même pas que ça existait), mais il est généralement préférable d'avoir quelquechose d'aussi simple que possible.  Exporter des données dans un fichier excel pour l'importer ensuite n'est donc pas une solution idéale, et n'est à envisager que si vous n'avez vraiment pas le choix.


Vous devriez donc voir si PCVue est capable de se connecter à postgres plutôt qu'importer un fichier.  Si ce n'est pas le cas, il serait probablement judicieux de choisir un outil plus adapté à la place.

Julien.
https://rjuju.github.io/
