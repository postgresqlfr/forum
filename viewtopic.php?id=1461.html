En fait, le SQL Server installé, je présume qu'il a été acheté non ? Il n'y a pas de support avec ? Je ne connais pas SQL Server, mais je sais que quand j'achète (chèrement) Oracle, j'ai un support que je peux contacter quand j'ai des soucis

Par contre, je ne sais pas si il y aura beaucoup de monde qui aura de l'expérience là dessus (sqlpro ?). Les migrations se font plutôt entre Oracle et PostgreSQL (dans les deux sens, malheureusement ), en ce qui me concerne en tout cas, je vois très peu de SQL Server.

Bref, pour SQL Server aucune idée. Je sais qu'habituellement les bases PostgreSQL sont légèrement plus grosses que les bases Oracle. C'est la plupart du temps dû à la gestion différente des transactions qui agrandit la taille des enregistrements dans PostgreSQL, ainsi qu'à l'implémentation de numeric, qui prend plus de place que sous Oracle.
