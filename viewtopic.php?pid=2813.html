pgadmin3 (RPM) sur suse 9.3 install dans repertoire de travail

Bonjour,
je veux installer pgadmin3-1.6.3-1.i586.rpm dans mon repertoire
et que tout se fasse dans le repertoire de travail afin de protéger
mon systéme (je veux garder mon gcc actuel par exemple)
il parrait que cela est correct
"rpm -Uvh *.rpm"

( je prefere demander avant de faire une boulette)


voir ce tuto
--------------

1) Quand on installe un rpm avec une ligne de commande de genre
"rpm -Uvh fichier.rpm" (ou "rpm -ivh ..." peu importe) il faut se placer dans le repertoire il y a le ficher rpm a installer.

2) Il faut etre connecte en root pour pouvoir installer. Ton message d'erreur indique que tu ne l'etais pas. Donc faire "su -", entrer le mot de pass de root et refaire.

3) Pour resoudre le probleme des dependances le plus facile est d'installer tous les paquets avec une seule commande comme:
"rpm -Uvh *.rpm"
(ca installe tous le rpm dans le repertoire actuel).

Marc tu en penses quoi ?

Re : pgadmin3 (RPM) sur suse 9.3 install dans repertoire de travail

Que ça va l'installer dans le système, pas dans ton répertoire. Mais ça n'est pas grave :
- il va refuser d'écraser des fichiers
- tu pourras désinstaller proprement. Donc rpm -Uvh pgadmin3-1.6.3-1.i586.rpm.
Mais ça ne peut pas marcher sur ton serveur : tu n'es pas en i586 mais en ia64. L'architecture processeur est incompatible.

Marc.
