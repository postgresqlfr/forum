Vous avez déjà ça : http://en.wikipedia.org/wiki/Comparison … nt_systems

Si c'est pour convaincre du management, vous pouvez aussi étudier les témoignages :
http://www.postgresql.org/about/users
http://www.postgresql.fr/temoignages:accueil

Par rapport à Oracle:
http://www.postgresql.org/about/press/faq
Vous ne trouverez pas beaucoup mieux Oracle ayant pour politique d'empêcher entre autres la publication de benchmarks non autorisés.

Par rapport à Mysql, même si c'est assez peu pertinent, Mysql s'adressant plutôt aux développeurs de forums PHP :
http://wiki.postgresql.org/wiki/Why_Pos … MySQL_2009
