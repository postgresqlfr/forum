Re : Mot de passe

Bonjour,
pour vos prochains problèmes il serait préférable de créer un nouveau thread.
Avez-vous un problème pour lancer postgres (dans ce cas c'est sous windows qu'il faut corriger le proglème) ou pour vous y connecter (dans ce cas ça se passe sur postgres) ? Vous semblez avoir des problèmes pour vous connecter mais le service tourne correctement. Si c'est le cas, il suffit de modifier le fichier pg_hba.conf, et de chercher une ligne de ce genre:
host    all             all             127.0.0.1/32            md5


et la remplacer par :
host    all             all             127.0.0.1/32            trust
En rechargeant (pg_ctl reload) ou redémarrant postgres, vous pourrez vous connecter depuis la même machine en utilisant l'ip 127.0.0.1 avec n'importe quel utilisateur. Vous pourrez alors redéfinir un nouveau mot de passe pour l'utilisateur postgres de la base.

Il faut changer votre connexion dans pgAdmin en remplaçant 192.168.x.y par 127.0.0.1
Vous pourrez alors vous connecter, et si vous le voulez changer le mot de passe de votre user de connexion.
Edit: Si votre application arrive à se connecter, c'est qu'elle a un user/mot de passe valide. Peut-être y a-t-il possibilité de récupérer le mot de passe via cette appli ? En tout cas si vous modifiez le mot de passe de l'utilisateur configuré sur cette appli, il faudra le répercuter dessus.
