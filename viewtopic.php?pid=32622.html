Exact, la migration des données devrait être très rapide.  Attention cependant, la difficulté habituelle pour ce genre de migration concerne la migration des procédures stockées plus que les données.  Ora2pg peut vous donner une estimation de l'effort nécessaire pour cela, ainsi que tous les autres écueils.  Voir https://ora2pg.darold.net/documentation … assessment
