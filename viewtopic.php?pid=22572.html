Re : Impossible d'installer correctement PostgreSQL

De mémoire l'étape de "post-installation" est un "initdb". Si l'installeur échoue, c'est probablement pour un problème de droits. Vous pouvez faire cette étape à la main sinon, voir http://docs.postgresql.fr/9.4/creating-cluster.html par exemple.

Re : Impossible d'installer correctement PostgreSQL

L'installeur doit laisser un fichier de log dans le répertoire %TEMP% de Windows. Celui-ci devrait vous dire la raison de l'échec. Je vous conseille sinon de suivre les différentes recommandations à l'adresse suivante : https://wiki.postgresql.org/wiki/Troubl … stallation

Au passage, la version 8.3 de PostgreSQL n'est plus maintenue depuis 2 ans et demie. Il serait peut être opportun d'installer une version plus récente d'OpenERP / Odoo, compatible avec une version plus récente de PostgreSQL.

Julien.
https://rjuju.github.io/
