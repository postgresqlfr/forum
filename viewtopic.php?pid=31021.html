Problème affichage des données dans l'éditeur de requêtes

Bonjour,

J'ai installé il y 2 semaines sous Windows 10, l'appli "pgadmin4" en version 4.20.
Avec cette appli, je me connecte sans souci à la base PostgreSQL que j'ai installé sur une machine virtuelle (PostgreSQL 11 et VM sous Debian 10 installée dans VirtualBox).

Mon problème est le suivant : bien que je puisse visualiser les données contenues dans ma base PostgreSQL depuis Windows avec Putty ou avec Qgis (pour les données géolocalisées), je n'arrive pas à les visualiser avec "pgadmin4" dans l'éditeur de requêtes.
Dans l'éditeur de requêtes de "pgadmin4", lorsque je fais une requête "SELECT", l'onglet "Données" ne renvoie rien. Pourtant sur l'onglet "message" j'ai un message m'indiquant que la requête s'est bien exécutée. Ci-après un message pour une de mes tables : "Exécution réussie. Temps total : 574 msec. 2780 lignes affectées.".
Egalement sous pgadmin4, les autres commandes SQL fonctionnent bien (create, insert, update, delete ....)

Auparavant, j'utilisais pgadmin III et je n'avais pas ce problème. J'ai fais le tour des paramètres de "pgadmin4" et regardé sur le web, mais je n'ai rien trouvé pour solutionner ce problème.

Est-ce que quelqu'un a une piste ?

Merci.
