synchronisé les fichiers de configuration

bonjour a tous

Projet de migration postgresql du version 9.5 vers la version 10

j'ai installer la nouvelle version sur la même serveur  maintenant j'aimerai charger le config des deux fichier postgresql.conf && pg_hba.conf  de l'ancien version et le mettre sur la nouvelle version ce ci bien sur avant import du donnée

sur l'internet je vient de trouver ces deux commandes ,

Qui a une retour d’expérience est ce que je peut le faire confiance  

diff /etc/postgresql/9.5/main/postgresql.conf /etc/postgresql/10/main/postgresql.conf
 
diff /etc/postgresql/9.5/main/pg_hba.conf /etc/postgresql/10/main/pg_hba.conf

merci pour vos retour d’expérience

Re : synchronisé les fichiers de configuration

Ces commandes vous montrerons les différences entre les deux fichiers dans un format spécifique.  À moins que vous ne soyez à l'aise avec ce format, je vous conseillerais plutôt de :


- réappliquer manuellement les changements sur le nouveau fichier de configuration.  La requête suivante devrait vous aider à récupérer les changements, à vous de voir ce que vous souhaitez garder : SELECT name, current_setting(name), source, sourcefile, sourceline FROM pg_settings WHERE (source <> 'default') AND name NOT IN ('config_file', 'data_directory', 'hba_file', 'ident_file');
- copier le pg_hba.conf à l'identique, à priori il ne devrait pas changer
