probléme Connexion localhost

Bonjour,
j'ai installé postgresql 9.3 sur mon localhost , j'ai essayé de me connecté via un autre PC du réseau j'ai changer les paramètres dans hpa.conf vers

host    all             all             0.0.0.0/0           md5

mais à peine ,
j'ai redémarré le service postgres ensuite j'ai constaté qu'au niveau postgres.conf le port à été changer vers 5433 j'ai essayé de me connecté mais j'ai seulement la base postgres mais toutes mes autres bases déjà crée ne sont pas accessibles .
j'ai essayé dechanger le port vers 5432 mais aussi à peine
j'ai changé dans hpa.conf la config vers
host    all             all             127.0.0.1/32           md5

aussi toutes mes bases ne sont plus accessibles .

Comment je les rend accessibles ?

Merci d'avance

Re : probléme Connexion localhost

Le port ne change pas tout seul. Soit un utilisateur soit un programme l'a changé. Et de ce que vous racontez, j'ai l'impression que vous avez deux instances installées. Bref, de toute façon, un changement du postgresql.conf et/ou du pg_hba.conf ne rend pas les bases inaccessibles. Un autre événement a eu lieu.

Guillaume.

Si vous êtes sur linux vous pouvez voir si plusieurs clusters tournent : ps -ef |grep postgres

S'ils ne tournent pas vous pouvez toujours faire une recherche (find) sur le FS pour voir si vous n'avez pas plusieurs postgresql.conf.

Quelle est la commande que vous utiliser pour vous connecter ?
