DBA Senior PostgreSQL Linux & Automatisation – Données 100% Cloud

Je suis recruteuse indépendante, et voici le poste que je vous propose en CDI à Paris Centre :


TAGS : PostgreSQL, Linux, AWS, S3, Ansible, Docker, Zabbix, Nagios, Ansible, Packer, Terraform, Go, HA Proxy, GIT, Jenkins, Scrum, PostgreSQL, Logstach, ElasticSearch, Kibana, jOOQ, Pgpool, PgBouncer, GIS (Geographic Information System)

La société : Editeur de logiciel/Start-up en forte croissance, qui adore la R&D

•    Ont levé 20 millions
•    R&D d’une 60aine de personnes
•    Vrai contexte agile : le Scrum est leur seule façon de travailler et est propagé à toute l’entreprise.
•    Attention très forte portée à la qualité du code
•    Culture d’entreprise tournée vers la veille technologique (BBL, formations)
•    Télé dans tous les bureaux pour avoir le feedback de Jenkins
•    « Choose Your Own Device » : Mac ou Linux, écran 24 pouces
•    Situé en plein cœur de Paris (Miromesnil)

Le poste : vous serez le centre de données de la société sur une application évolutive avec beaucoup de nouvelles features qui dépendent de la base de données

Le contexte : Linux, Cloud

•    Vous serez le seul DBA au sein d’une équipe Ops (6 personnes)
•    Charge des serveurs : milliers de requêtes/jour
•    Augmentation de la taille des datas des clients : actuellement base de 1 terra
•    Tous les serveurs sont des GNU/Linux. Tout est sur le Cloud (AWS, OVH, Google Cloud). Aujourd’hui il y a plusieurs plateformes AWS qu’ils veulent unifier et industrialiser
•    Très bonne entente avec l’équipe de dev
•    Utilisation de l’anglais

Les tâches : vous devrez répondre à beaucoup de besoins en même temps

•    Administrer et monitorer des 100aines de base de données : 600 serveurs dont 200 de bases de données
•    Gérér les back-up
•    Effectuer les tests de restauration
•    Check CPU, rame, disque
•    Conseiller les développeurs pour les requêtes et les shémas de bases
•    Complexité : automatiser avec Ansible pour que cela rentre dans les containers Utilisation de Kubernetes (configurer la base et le système d’exploitation)
•    Garantir le fonctionnement de la partie BI
•    Encadrer un junior DBA qui arrivera dans l'année

Le profil : DBA PostGreSQL Linux automatisation

•    Minimum 5 ans d’expérience DBA
•    Minimum 2 ans sur une Infra Cloud
•    Vous avez déjà manipulé Ansible, Puppet ou Chef
•    Vous avez une connaissance très approfondie sur Linux
•    Vous êtes pointu sur l’automatisation sur du Cloud et/ou vous connaissez bien les process de développement
•    Vous êtes capable d’expliquer les choix réalisés et êtes à l’écoute des développeurs

Vous avez envie de travailler en équipe sur des sujets stimulants, de venir apporter votre expertise à une équipe soudée, pleine de dynamisme et de bonnes pratiques ? Envoyez-moi votre CV :
