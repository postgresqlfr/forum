Bonjour,

non ni postgresql ni pl/java n'intègre de machine virtuelle. Comme indiqué dans la documentation de pl/java, il est nécessaire de disposer d'une machine virtuelle et d'indiquer à pl/java où la trouver (par exemple pour linux : https://github.com/tada/pljava/wiki/Ins … r-*nix%29)
