quel logiciel (commercial ou pas) pour analyser les log de postgresql

bonjour,


je suis à la recherche d'un outil qui analyse les logs de postgresql sous windows.

Lequel me conseillez-vous ?

J'en cherche un qui me permette de détecter quelle requête est le plus faite avec son temps moyen ?
et aussi qui me classe les requêtes les plus longs qqsoit le nombres d'exécutions.

par exemple, si il voit dans les log ceci :

update matable set champ1=45 where id=12
update matable set champ1=46 where id=13

et me sortirait dans un table une analyse comme ça :

Nb execution   |moy. temps exec | requete
________________________________________________
2                  |  12ms               | update matable set champ1=INTwhere id=INT


Si possible, il faut qu'il fonctionne sous windows, avec pg 8.2.

merci de vos conseils.

Bonjour.
Il existe pgFouine (http://pgfouine.projects.postgresql.org/) qui fait exactement cela. C'est un script php qui analyse des log sous un certains format, donc utilisable sur n'importe quel environnement faisant tourner php.
