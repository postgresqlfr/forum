Bonjour,

Après avoir installé PostgreSQL avec succès sur ma machine, j'aimerais en faire de même sur Windows Server 2003.
Lors de l'installation, j'obtiens un jolie "the service user account 'postgres' could not be created" sur la fenêtre de Password pour le superuser 'postgres'.
J'ai fais des recherches partout et je n'ai rien trouvé de satisfaisant. J'ai les droits admins et j'ai essayé avec des mots de passes différents, compliqués, simples ... L'utilisateur 'postgres' n'existe pas.

Merci de votre aide !

Re : the service user account 'postgres' could not be created

J'ai finalement réussi à trouver une solution, enfin... La voici pour les futurs utilisateurs qui rencontreraient le même problème :

1.    Désinstaller PostgreSQL si celui-ci est déjà installé
2.    Supprimer le dossier « data » (s’il existe) : rd /s /q "D:\Program Files\PostgreSQL\8.4\data"
3.    Créer un nouvel utilisateur nommé postgres en remplissant les champs comme ceci :
           •    Nom : postgres
           •    Nom d’ouverture de session de l’utilisateur : postgres
           •    Mot de passe : "un_mot_de_passe_pas_trop_court"
4.    Créer un dossier « PostgreSQL » sur le disque où vous souhaitez installer PostgreSQL (par ex: D: )
5.    Dans le dossier « PostgreSQL », créer un dossier « 8.4 »
6.    Donner toutes les permissions sur le dossier PostgreSQL pour l’utilisateur postgres :
cacls D:\PostgreSQL /E /T /G VOTRE_DOMAINE\postgres:F
(Si la commande venait à ne pas fonctionner, faites clic-droit sur le dossier --> Sécurité --> cocher toutes les autorisations pour le groupe Utilisateur)
7.    Lancer l’exécutable pour installer PostgreSQL.

IMPORTANT : Veuillez à ne pas installer PostgreSQL dans « Program Files » mais de préférence à la racine d’un disque dans un dossier qui lui est propre comme nous l’avons fait. Ceci évitera des éventuelles erreurs lors de l’installation également dû à des problèmes de droits (courant avec Windows 7).
