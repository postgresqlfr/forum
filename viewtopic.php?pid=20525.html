Re : Problème de Connexion au serveur pgAdminIII

Il n'y a pas moyen de le retrouver. Pour le réinitialiser, il va falloir se connecter sans mot de passe, puis mettre à jour le mot de passe.

Pour se connecter sans mot de passe, éditez le fichier pg_hba.conf et indiquez trust à la place des méthodes d'authentification (certainement md5 actuellement). Pensez à dupliquer le fichier pg_hba.conf avant de le modifier pour pouvoir revenir simplement à la précédente configuration. Redémarrez PostgreSQL. pgAdmin devrait permettre la connexion sans mot de passe. S'il vous en demande un, indiquez n'importe quoi, ça devrait aller si la configuration s'est bien effectuée. Une fois dans pgAdmin, changez le mot de passe de l'utilisateur. Puis changez de nouveau le fichier pg_hba.conf pour revenir à la configuration précédente.

Guillaume.

Re : Problème de Connexion au serveur pgAdminIII

Je pense que windows sauvegarde un hash du mot de passe ce qui explique que la longueur affichée est sans rapport avec la taille réelle du mot de passe. De mémoire le couple (utilisateur,mot de passe) est validé lors de la saisie dans les options du service. Si vous saisissez un mot de passe erroné il devrait vous afficher un message d'erreur.


Pour le nouveau message d'erreur, vous pouvez le recopier ou faire une capture d'écran, il existe beaucoup de service de partage d'image gratuit (tyinypic ou image-share par exemple).

Julien.
https://rjuju.github.io/
