connexion perdue en créant une extension postgis

Bonjour,

Je bute... Quand j'essaye d'ajouter l'extension postgis à une base (create extension postgis;) j'obtiens le message :

server closed the connection unexpectedly
    This probably means the server terminated abnormally
    before or while processing the request.
The connection to the server was lost. Attempting reset: Failed.

2017-12-19 15:44:02 CET [20807-7] LOG:  server process (PID 21127) was terminated by signal 6: Aborted
2017-12-19 15:44:02 CET [20807-8] DETAIL:  Failed process was running: CREATE EXTENSION postgis
2017-12-19 15:44:02 CET [20807-9] LOG:  terminating any other active server processes
2017-12-19 15:44:02 CET [21019-2] WARNING:  terminating connection because of crash of another server process

J'ai tenté de multiples désinstallations/résintallations, en me référant notamment à ce poste : https://stackoverflow.com/questions/274 … -on-ubuntu

Mais je bloque... Quelqu'un aurait-il une idée ? Un grand merci !

Re : connexion perdue en créant une extension postgis

C'est peut-être une incompatibilité de version ou d'options de compilation entre ce postgres et ce postgis.

Quelles sont les versions des deux et de quelles sources viennent-ils? Compilation perso? Packages? Quelle(s) source(s) de packages?

Ce qu'on peut dire sur le log ci-dessus est que "signal 6: Aborted" est dû au programme lui-même qui appelle abort(). Que ce soit postgresql ou postgis qui le fait, difficile à dire. On peut aller plus loin avec un fichier core et/ou une trace:

https://wiki.postgresql.org/wiki/Genera … QL_backend
