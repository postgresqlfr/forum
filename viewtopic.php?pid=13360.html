Re : inventaire des données

Si vous voulez donner à votre personnel la possibilité de voir le contenu des tables, je pense que la seule solution est de développer un petit site web se connectant à postgres et permettant de consulter ces données mises en forme.

Il y a également l'outil PhpPgAdmin qui est l'équivalent de pgAdmin mais en plateforme web.
Cependant, cet outil ne sera pas capable de synthétiser les données ou d'y ajouter une mise en forme spécifique comme une appli web maison.

pg_tables est une vue permettant d'afficher la liste des tables d'une base de données avec quelques informations supplémentaires. Vous pouvez lire http://docs.postgresqlfr.org/9.1/view-pg-tables.html pour plus de détails.

Julien.
https://rjuju.github.io/
