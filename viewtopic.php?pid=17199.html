Re : connexion à un autre serveur

Bonjour,

il est préférable de créer un nouveau sujet pour votre problème.

Sinon, sur postgres les bases sont hermétiques, il n'est donc pas possible d'appeler une table d'une autre base nativement. Vous pouvez regarder du côté de dblink (http://docs.postgresql.fr/9.2/contrib-d … ction.html) pour contourner cela.

Julien.
https://rjuju.github.io/
