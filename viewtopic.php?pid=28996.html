Re : utilité de fichier recovery.conf

Techniquement le fichier recovery.conf doit être mis dans le répertoire principal de données, alors que le postgresql.conf peut être ailleurs.  C'est un piège classique sur ubuntu et debian, où les postgresql.conf n'est pas dans le répertoire de données.
