Re : pgadmin 1.16.1 / postgresql 9.2.3

Qu'entendez-vous par "les requêtes ne se libèrent pas" ? Depuis la version 9.2, le champ query contient la dernière requête exécutée si la connexion est inactive (le champ state donne l'information). Comme pgAdmin reste connecté, il est normal de voir des données dans cette colonne.

Pour le problème "les instruments ne sont pas installés", il faut créer l'extension adminpack sur les bases voulues (create extension adminpack).

Si des requêtes restent présentes, c'est que vous avez un problème sur votre applicatif, ou un pooler de connexion.

Pour créer l'extension il suffit de taper la requête donnée dans mon précédent message. Voilà la documentation : http://docs.postgresql.fr/9.2/sql-createextension.html
