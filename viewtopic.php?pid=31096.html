Re : "L'initialisation du cluster de bases de données à échoué"

Bonjour,


oui il faut rajouter un serveur dans pgAdmin. La configuration dépend de votre installation. Si vouss avez installé en local avec les paramètres par défaut, utilisez les paramètres suivant:


Name: ce que vous voulez. Host: localhost. Port: 5432. Password: celui que vous avez saisi lors de l'initdb, sauf si authentification en "trust" dans le fichier pg_hba.conf auquelcas laisser vide.

Julien.
https://rjuju.github.io/
