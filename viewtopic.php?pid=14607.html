Dans une requête sql, essayez de lancer cette requête :

select c.oid,relname,relkind
from pg_class c
where relname ilike 'propri%t%';

et dites moi quelle est le résultat.
Edit : mettre ilike 'propri%t%'; et non pas ilike 'propri%t%s'; (ne pas mettre le s à la fin)

Re : Création d'un SGBD en local puis migration vers un serveur

Je ne vois vraiment pas le problème, peut-être que quelqu'un connaissant plus pgAdmin pourra vous éclairer.
Vous pouvez cependant lancer la restauration en ligne de commande (c'est de toutes façons ce que fait pgAdmin).
Voilà la doc pour l'utiliser : http://docs.postgresqlfr.org/9.1/app-pgrestore.html
Un exemple simple pour vous si votre serveur est en local pourrait être :
"C:\Program Files\PostgreSQL\9.1\bin\pg_dump.exe" -h 127.0.0.1 -U postgres -d nom_de_votre_base nom_fichier.backup

Julien.
https://rjuju.github.io/
