Re : error after restoring a db

This is a french web forums about PostgreSQL. There are better options for english help, for example PostgreSQL Mailing lists.

Anyway, on your issue, it seems you're trying to restore your dump in the old database. The first error message, and a lot of others are like this : ERROR:  constraint "infodht_invhwtype_fk" for relation "infodht" already exists ... it cannot restore your object because it already exists. You have to make sure that the database is empty (or at the very least, doesn't already contain objets of the same name).

rjuju

Re : error after restoring a db

L'erreur ne semble pas majeure car par défaut la restauration n'est pas faite dans une unique transaction. Vous êtes donc dans un état un peu bancal où certaines données sont restaurées et d'autres non.

Pour les erreurs de restauration, pour ma part pas trop d'idée. Vous avez une erreurs toutes les 3 contraintes ?
A tout hasard, , vous pouvez vérifier sur la base originale quelles sont les contraintes avant et après une des contraintes en erreur, peut-être y a-t-il un problème à ce niveau là, par exemple :

SELECT * FROM pg_constraint WHERE oid IN (3212528,3212529,3212530)
pour voir les 3 premières contraintes restaurées

ou

SELECT * FROM pg_constraint WHERE conname = 'infodht_invhwtype_fk'

S'il y a des doublons cela expliquerait l'erreur (et indiquerait un problème sur la base aussi).

Julien.
https://rjuju.github.io/
