bonjour tout le monde,
j'ai installé la dernière version disponible de postgresql mais à la fin de l'installation la message d'erreur suivant s'affiche:
"Un problème est survenu lors de l’exécution de l'étape de post-installation. l'installation peut avoir échoué. L'initialisation du cluster de base de données a échoué "

quand j'ouvre le pgadmin le serveur PostgresSQL 9.4(localhost:5432) existe mais c'est inutile de l'ouvrir, le message suivant s'affiche:
Server doesn't listen
The server doesn't accept connections: the connection library reports
could not connect to server: Connection refused (0x0000274D/10061) Is the server running on host "localhost" (::1) and accepting TCP/IP connections on port 5432? could not connect to server: Connection refused (0x0000274D/10061) Is the server running on host "localhost" (127.0.0.1) and accepting TCP/IP connections on port 5432?

"C:\Program Files\PostgreSQL\9.4\bin\initdb.exe" -D "C:\Program Files\PostgreSQL\9.4\data"
