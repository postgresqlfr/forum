Re : Impossible d'installer Postgresql

Bonjour.

Y a-t-il eu un évènement sur le pc ou est isntallé postgresql ? (crash système ...)

Lancez-vous le gestionnaire de service avec un compte administrateur ? Et le service postgresql est-il bien configuré pour se lancer en tant qu'utilisateur postgres (ou autre non administrateur) ?

Sinon, vous pouvez regarder dans le répertoire de log (généralement c:\Program Files\Postgresql\8.3\pg_log\) les fichiers log les plus récents et voir la cause du dernier arrêt, ou s'il y a plus d'information sur le blocage du lancement.

Vous pouvez également regarder dans l'observateur d'évènement pour chercher plus d'information sur l'erreur lors du démarrage de la base de donnée.

Pour pgAdmin, il ne pourra pas se connecter tant que le serveur ne sera pas actif.

Re : Impossible d'installer Postgresql

L'observateur d'évènement se trouve dans le panneau de configuration -> outil d'administration -> observateur d'évènement.

Je pense que les erreurs postgresql doivent se trouver dans l'onglet "Application".

Pour le répertoire, j'ai oublié de spécifier que le répertoire pg_log se trouve dans le sous répertoire "data" dans le répertoire 8.3 (ou 9.1 selon votre version en ce moment).
