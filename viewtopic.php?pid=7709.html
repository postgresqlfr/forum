Migration PostgreSQL 8.3 Windows sous PostgreSQL 8.3 Debian Lenny

Bonjour,

J'essaie de migrer ma base PostgreSQL de Windows vers un serveur Linux.

J'ai copié les fichiers de données et de conf, mais lorsque je veux redémarrer le serveur postgresql, le message d'erreur suivant apparait:

Restarting PostgreSQL 8.3 database server: mainError: The server must be started under the locale French_France.1252 which does not exist any more.

Je n'arrive pas à trouver comment convertir la base, ou quel fichier de conf modifier.

Re : Migration PostgreSQL 8.3 Windows sous PostgreSQL 8.3 Debian Lenny

Vous ne pouvez pas recopier les fichiers de données d'un serveur à un autre, si le système d'exploitation n'est pas identique (et les options de compilation d'ailleurs). Cette manipulation ne peut pas marcher. Il faut passer par un pg_dump (ou pg_dumpall) et une restauration sur le nouveau serveur.

Marc.
