Re : Server doesn't listen

Quelques informations préalables : je sais ce qu'est OpenERP (à savoir, un ERP ), mais je n'ai aucune idée de comment il s'installe. Comme apparemment vous ne faites référence qu'à OpenERP et que moi je ne connais que PostgreSQL, on risque d'avoir un problème de communication

Ce que je peux dire d'après votre texte, c'est que le message :

Connection refused (0x0000274D/10061)
Is the server running on host "localhost" (::1) and accepting
TCP/IP connections on port 5432?

est un message qui vient de PostgreSQL. Il indique que le serveur n'a pas démarré. Vous indiquez après que le répertoire data est vide. Cela explique pourquoi PostgreSQL ne démarre pas. Il ne peut pas démarrer avec un répertoire data vide.

Que pouvez-vous faire à partir de là... à mon sens, il faut désinstaller OpenERP et PostgreSQL. Il faut vraiment s'assurer que les deux soient entièrement desinstallés. Donc exécutez la désinstallation, puis vérifier qu'il n'existe aucun fichier des deux. Puis procédez à l'installation. Si jamais vous installez PostgreSQL vous-même (ie, ce n'est pas l'installeur d'OpenERP qui le fait), vérifiez que le répertoire data est bien peuplé avant de procéder à l'installation d'OpenERP. Et vérifiez après l'installation de tout que le répertoire data n'est toujours pas vide.

Guillaume.

Re : Server doesn't listen

Vous parlez d'un fichier data puis d'un répertoire data, ce n'est pas  très clair. Vous devriez avoir un répertoire contenant de nombreux fichiers et sous répertoires (base, pg_tblspc, postgresql.conf...). Si ce répertoire est vide, c'est sur qu'il n'y a pas d'instance postgres. Si vous avez copié des données depuis un répertoire équivalent d'une autre machine et que la copie ne marche pas, il faut plutôt regarder du côté de windows, pas de postgres.
