Re : Démarre sur PostgreSQL : Se connecter à un dossier

> Comment "récupérer les données (tables, shapefile) d'un dossier pour pouvoir travailler dessus ?

Il n'y a pas de notion de dossier dans les SGBD, donc je ne vois pas trop ce que vous cherchez. Vos tables sont dans des schémas, qui eux-même sont dans des bases de données.

> Question bête surrement, mais où écrire les requêtes SQL ? j'ai tenté SQL Shell mais je ne comprends pas toutes les questions en entrée Server [localhost], etc. Est-ce là que je fais ma connexion avec mon dossier ?

SQL Shell vous le permettrait mais ce n'est pas le plus simple. Pour débuter, mieux vaut utiliser l'outil Query Tool fourni par pgAdmin.

> Comment passer de pgAdmin 4 à PostGIS qui permet de manipuler des données shapefile ?

En soit, la question n'a pas de sens. pgAdmin4 est un outil qui permet d'accéder à une base de données PostgreSQL, qui elle-même contient l'outil PostGIS. Donc à partir du moment où vous vous connectez à une base de données PostgreSQL contenant PostGIS, vous pouvez exécuter des requêtes SQL sur des données GIS.

> Existe-il des formations sur PostgreSQL 10 que vous préconisez (livre, formation en live, dans des centres de formations, etc.) ?

Nous ne préconisons pas d'entreprise en particulier, vu que les différents intervenants de ce forum travaillent dans des sociétés différentes et généralement concurrentes. La liste des sociétés fournissant des formations sur PostgreSQL pour l'Europe se trouve sur https://www.postgresql.org/support/prof … rt/europe/.

Concernant les livres, pour débuter, celui de Sébastien Lardière me paraît parfait (https://www.editions-eni.fr/livre/postg … 2409011467).

Guillaume.
