Re : createuser bug

psql est la console interactive de PostgreSQL, pas le serveur.

Vous devez avoir un script de démarrage dans /etc/init.d pour lancer PostgreSQL. Il vous suffit de faire un "/etc/init.d/nom_du_script start" pour le démarrer.

Maintenant, pour être franc, si vous confondez psql et postgres, c'est que vous avez beaucoup à apprendre sur PostgreSQL. Et le mieux est certainement de commencer avec le manuel, dont vous trouverez une version traduite sur http://docs.postgresql.fr/8.4/ .

Guillaume.
