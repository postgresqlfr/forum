C'est étrange que le fichier pg_hba.conf n'existe pas. Vous pouvez essayer d'en créer un avec ce contenu :

host       all       all       127.0.0.1/32       trust

Celui-ci indique que postgres autorise la connexion en local sans fournir de mot de passe.
