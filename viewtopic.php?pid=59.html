Re : importation de données

pgloader est codé en python donc ça doit fonctionner sous windows sans trop de problèmes, pour peu que tu installes les paquets python nécessaires ( psycopg, ... )

Tu peux également regarder des solutions alternatives telles que :

  * benetl : http://www.benetl.net/
  * talend : http://www.talend.com

Tout dépend du niveau de complexité des données que tu souhaites importer....
