Re : [probleme] connexion postgres error: "serveur doesn't listen"

Le paramètre listen_addresses se trouve dans le fichier postgresql.conf. Ce fichier doit se trouver normalement (sous XP) dans C:\Program Files\PostgreSQL\8.3\data si l'installation a bien eu lieu dans C:\Program Files\PostgreSQL.

À priori, pour savoir s'il est bien démarré, ça doit se voir dans le panneau de configuration Services de Windows.

Guillaume.

Re : [probleme] connexion postgres error: "serveur doesn't listen"

Il serait bien de créer une nouvelle discussion, plutôt que d'enchaîner tous les problèmes dans la même. Pas grave pour cette fois, mais il serait bien d'y songer pour la prochaine.

Le message d'erreur indique que l'alias localhost n'est pas reconnu. Si vous faites un « ping localhost », quel est le résultat ? si jamais le message d'erreur est identique, il faudrait trouver le fichier hosts dans C:\Windows et vérifier que la ligne localhost n'existe pas. Si c'est bien le cas, il faut ajouter la ligne suivante :

127.0.0.1       localhost

Autre solution, remplacez localhost par 127.0.0.1 dans la déclaration du serveur (dans pgAdmin).

Guillaume.
