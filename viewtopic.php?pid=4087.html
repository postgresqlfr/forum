Re : Probleme, posgresql

Comme indiqué : le port 5432 est déjà utilisé d'après le système (ou du moins pas utilisable)
Deux possibilité :
- Vous avez déjà un autre postgresql démarré sur la machine qui prend ce port
- Vous êtes sous windows et avez un antivirus qui empêche postgresql de prendre le port. Si c'est le cas, désactivez le et réessayez

Marc.
