Re : Problème de connexion

L'installeur a donc planté sur la partie initdb (le fameux post-install step).

Il faut relancer l'installeur, avec les privilèges administrateur, et vérifier que l'installation se passe bien. Si ce n'est toujours pas le cas, un fichier de log doit être présent dans le répertoire temporaire de windows (démarrer -> exécuter -> %TEMP%). Il devrait contenir la raison de l'echec d'initdb.

rjuju

Re : Problème de connexion

Vous pouvez toujours le faire à la main, si le répertoire data est vide:

initdb.exe -U postgres -D "C:/Program Files/PostgreSQL/9.1/data" (supprimer le répertoire data si besoin)

pg_ctl.exe register -N Postgresql_9.1 -U postgres -P mot_de_passe -D "C:/Program Files/PostgreSQL/9.1/data" -S auto -w -t 10

vous devriez ensuite pouvoir démarrer le service.

Julien.
https://rjuju.github.io/
