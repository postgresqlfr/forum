Re : Problème de création de base de donnée

Bonjour,

Si vous avez oublié ou perdu le mot de passe de postgres, vous pouvez toujours mettre le pg_hba.conf en mode trust et relancer le service postgres.
Ensuite vous vous connecter au cluster et vous modifier le mot de passe de postgres (alter user postgres with password 'mon_password';).
Une fois que c'est fait vous pouvez remodifier le pg_hba.conf avec une méthode d'authentification de votre choix.

Cordialement,

Cordialement,

Sébastien.
