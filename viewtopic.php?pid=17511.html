Re : Problème d'installation de PostgreSQL 9.2 (32 bits) sur W7

Le rapport c'est que si vous n'avez pas les droits suffisant, il faut faire manuellement toutes les étapes faites par l'installeur (créer un utilisateur spécifique, initialiser le cluster, démarrer le moteur ...).

De mémoire l'installeur postgres pour windows n'est pas open source. C'est à la personne qui installe postgres de s'assurer qu'il dispose bien des droits adéquats (créer un utilisateur, créer un service, donner le droit d'ouvrir une session en tant que service ...).

Le log d'installation se trouve dans votre répertoire %TEMP% il me semble, et non pas dans le répertoire de postgresql (ces deux fichiers sont sans rapport).
