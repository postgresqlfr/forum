Re : Probleme migration MySQL PostgreSQL

Bonjour,

vous dites que le serveur est sous windows 7 et le client sous xp, or le message indique "localhost". S'agit-il d'un test de connexion depuis le serveur ou depuis le client ? Si vous voulez vous connecter depuis une autre machine,  il faudra rajouter dans le pg_hba.conf une ligne du type

host    all             all             192.128.0.0/24            md5

(si votre réseau local est en 192.168.0.0 bien entendu) et faire un reload de la configuration.
